Features

九项核心优化

每一项都针对红魔手机的痛点，通过 sysfs 节点直接调优内核参数，配置文件一键开关。

风扇极速

5 档可调风扇转速，解锁被限制的风扇性能，散热拉满。

/sys/kernel/fan/

电池保护

云端限制

Installation

安装步骤

仅需三步即可完成安装和启动。

1

安装 KernelSU

确保你的红魔手机已经完成 Root，并安装了 KernelSU 管理器（KernelSU Manager）。

2

刷入 FanExtreme 模块

从 GitHub Releases 下载 ZIP 文件，在 KernelSU 管理器中点击「安装模块」并选择 ZIP 文件。也支持从在线更新频道直接安装。

3

重启设备

重启手机后模块自动生效。可通过编辑 /data/adb/modules/FanExtreme/config.txt 来开关各项功能。

Configuration

配置文件

通过 config.txt 控制每项功能的开关。格式为 键值=值，1 = 开启，0 = 关闭。

config.txt
# 0=关闭 1=启用 风扇极速 = 1 充电分离 = 1 充电分离阈值 = 100 云控屏蔽 = 1 温控移除 = 1 振动增强 = 1 振动增益 = 168% 振动时长 = 18ms 振动上限 = 128 触控优化 = 1 充电加速 = 1

Technical

Sysfs 接口

模块通过 sysfs 节点直接与内核交互，以下是主要操作路径。

/sys/kernel/fan/fan_speed_level 风扇速度等级 (1-5)
/sys/kernel/fan/fan_enable 风扇开关控制
/sys/class/qcom-battery/restrict_cur 充电限制电流
/sys/class/qcom-battery/restrict_chg 充电限制开关
/sys/class/qcom-battery/charging_enabled 充电使能控制
/sys/class/qcom-battery/charge_mode 充电模式选择
/sys/kernel/gpu/ GPU 调频与负载信息
/sys/devices/system/cpu/cpu*/cpufreq/ CPU 调频与 Governor 设置
