# FanExtreme—更好的红魔

红魔手机 KernelSU 模块 | 风扇极速 · 充电分离 · 云控屏蔽 · 温控移除 · 振动增强

## 功能

| 功能 | 说明 |
|------|------|
| 风扇极速 | 开机自动拉到最高档（level 5），锁死风扇速度节点 |
| 充电分离 | 电量达到设定阈值自动启用，电池不充电，USB 直接供电 |
| 云控屏蔽 | 解锁→清空→锁定 cube 云控目录，杜绝远程下发频率限制 |
| 温控移除 | 所有温度墙拉到 95°C，替换 thermal-engine.conf |
| 振动增强 | 自定义 AW8697 线性马达增益/时长/刹车参数 |

## 安装

1. 下载 `FanExtreme-vX.X.X.zip`
2. KernelSU Manager → 模块 → 从存储安装
3. 重启

## 配置

模块目录下的 `config.txt`：

```
0=关闭 1=启用
风扇极速=1
充电分离=1
充电分离阈值=100
云控屏蔽=1
温控移除=1
振动增强=1
振动增益=168%%
振动时长=18ms
```

重启后生效。

## 兼容性

理论支持全版本红魔机型。已在 NX769J (红魔 9 Pro, Android 16) 测试通过。
